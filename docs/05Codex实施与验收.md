# 9 AI 能力与数据使用策略

## 9.1 公共 AI 服务

平台 AI 服务负责连接配置、密钥引用、模型请求、流式事件、取消、超时、有限重试和使用记录。小说提示词、正文证据选择及候选采用由墨稿负责。其他模块可以不声明 ai.request，平台不能在后台默认对所有内容做 AI 分析。

API 密钥保存在系统凭据存储，由 Rust 获取；普通数据库只存 secretRef。凭据存储不可用时允许本次会话使用内存密钥，明确显示未保存，绝不明文退回 localStorage、日志或备份。应用关闭清除会话密钥。UI 输入后只显示掩码，修改与删除凭据提供明确结果。

自定义服务地址由用户明确配置，默认 https；localhost 或 127.0.0.1 可用于本地服务。其他 http 地址需用户知悉传输限制。请求不跟随跨来源重定向，密钥只发送到选定连接。日志只保存错误类型与状态码，不记录 Authorization 或完整请求正文。

## 9.2 请求契约

AiRequest 包含 requestId、moduleId、entityScope、connectionId、operation、messages、baseRevision、settingsRevision、maxOutput 和 timeout。模块按需传入正文，AI 服务不自行遍历资料。流式事件包含 requestId、sequence、type 和 payload，type 至少为 started、delta、completed、failed、cancelled。前端按请求归属和序号处理，completed 是唯一完整结束信号。

首版同时最多运行 2 个 AI 请求，每个作品的同类写作操作最多 1 个。连接超时基线为 15 秒，无数据超时为 60 秒，总超时为 180 秒，可在设置中查看。只在未产生输出时允许最多 1 次自动重试；流式已产生输出后由用户手动重试，避免重复计费和误拼接。取消不表示提供商一定停止计费。

操作状态为 pending、running、succeeded、failed、cancelled、interrupted；批量任务可增加 partial。用户取消后不接收可采用的完整结果。应用重启时 running 转为 interrupted，不自动恢复外部请求。待采用结果本地持久化，正文不受其失败影响。

## 9.3 上下文与费用

请求前可查看选中的设定、正文和资料片段，按模块操作选择，不默认上传整部作品。上下文由第 4 节编译器按预算构建。字符估计不能标成准确 token 数；实际用量只在提供商返回时记录。价格需用户配置，显示币种、单价日期和“估算”，无价格时只展示已知用量。

首版不设置模型自主管理文件、执行命令或直接保存小说的工具能力。模型输出都是内容或结构化候选，持久化仍经领域校验与用户操作。提供商响应缺字段、非法 JSON 或引用不符时明确失败，不以空内容伪装成功。

# 10 非功能要求与验证基线

## 10.1 性能与容量

以下是首版验收目标，不是已测结果。基准机器为近年 4 核及以上、16 GB 内存、SSD；记录具体系统、硬件、构建模式及测试数据。正式打包版本测量，排除首次安装与迁移。

| 项目 | 目标与测试条件 |
| --- | --- |
| 冷启动 | 连续 10 次正常启动，至少 9 次在 3 秒内可操作 |
| 普通页面切换 | 50 次操作 p95 不超过 300 ms；不含大附件预览 |
| 全局搜索 | 100 项目 10000 资料 1000 笔记 5000 任务，查询 p95 不超过 1 秒 |
| 编辑 | 单章 20000 中文字符，持续输入及组合输入不明显卡顿；不得每个按键扫描全书 |
| 长篇容量 | 1000 章 总计 200 万中文字符；树与书架分页，打开一章不加载全书正文 |
| 任务响应 | 长任务后台执行，取消在下一个安全点响应；通常 3 秒内反馈正在停止 |
| 保存 | 10000 字笔记或章节本地保存 p95 不超过 500 ms；失败状态可见 |

性能目标未通过时，先定位查询、序列化和索引瓶颈并修复；需要调整时提交实测证据与决策记录，不能自行改低指标后宣布验收完成。AI 速度与提供商有关，不计入普通页面与保存指标。

## 10.2 可靠性

必须验证保存回执、崩溃恢复、版本冲突、磁盘写入失败、数据库迁移失败、缺失附件及损坏备份。长任务失败保留已提交内容并报告部分成功范围。多个窗口或第二个应用进程不能并发写同一空间，首版使用单实例与单工作空间写锁。

全局搜索与派生摘要都是投影，损坏时可重建而不损坏正文。生产错误要有稳定编号和可重试动作。应用启动失败不自动创建一个新空库来掩盖原库无法打开的问题。

## 10.3 安全与隐私

界面使用明确的 Tauri capabilities 与 CSP，仅授予所需原生能力。Rust 命令校验输入、路径及实体归属。禁止远程网页获得本地文件或命令权限；外部网页在系统浏览器打开。渲染用户内容时不执行脚本，富文本允许节点与导出 HTML 均受白名单约束。

本地数据库和附件首版不提供应用级全文加密，依靠系统账户与磁盘保护；界面不把普通备份称为加密备份。密钥单独存放。清除 AI 凭据与删除作品是不同动作。平台默认无遥测、无后台内容上传，诊断由用户主动导出。

## 10.4 可维护性与兼容性

TypeScript strict、前端类型检查、Rust 格式检查、clippy 与关键测试均通过。依赖锁文件提交，基础功能依赖不能反向引用小说目录。公共接口通过小规模契约测试覆盖空值、枚举、ID 和错误。重要决策记录理由与替代方案，组件按职责拆分，不以统一行数限制代替设计。

macOS 为先验收平台，Windows 使用独立构建环境验证中文路径、文件对话框、快捷键、凭据存储、备份与安装。WebView 下中文输入、富文本选区及拖入文件需实测。Linux 与移动端列为后续。安装包能生成不代表签名与公证已完成；公开分发凭据需要另行提供。
