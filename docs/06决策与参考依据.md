# 13 风险 默认值与参考依据

## 13.1 关键风险

| 风险 | 影响 | 应对与触发条件 |
| --- | --- | --- |
| Rust 与界面跨语言契约漂移 | 保存字段或枚举解释不一致 | S01 建 DTO 契约测试，每次接口变化执行两端检查 |
| WebView 编辑器行为差异 | 输入法 选区和快捷键异常 | S00 验证中文输入，S06 双平台实机检查 |
| 基础系统范围失控 | 平台长期停留在框架阶段 | S03 以独立闭环验收，后续功能另列版本 |
| AI 候选覆盖新内容 | 作者稿件损失 | Rust 层版本条件与幂等采用，快照同事务 |
| 派生数据与正文脱节 | 后续生成依据错误 | 来源版本 引用 校验与 stale 规则 |
| 备份看似成功但缺附件 | 恢复内容不完整 | 一致性快照 附件清单 哈希与新安装恢复测试 |
| 模块边界逐渐失控 | 增加模块反复修改平台 | 依赖方向检查，跨模块只用公开接口 |
| 系统凭据存储不可用 | AI 连接无法安全持久化 | S00 验证，降为明确的会话密钥而非明文存盘 |
| 单设备损坏 | 本地备份一并丢失 | 提供外部导出，界面显示实际备份位置 |

| --- | --- | --- |

| 操作系统优先级 | macOS 优先，Windows 在小说版发布前验收 | S00 记录 Windows 验证环境 |
| 首版存储与账号 | 单用户 单本地工作空间 无账号系统 | S01 数据模型冻结前 |
| 小说重写范围 | N01 至 N08，长篇优先，短篇采用单章 | S04 开始时可细化不增加旧系统兼容 |

云同步、多工作空间、第三方动态插件和 AI 自动批量处理若成为明确需求，需要独立设计；不能把“可扩展”解释为当前必须实现所有基础设施。

## 13.3 决策记录

ADR01 选定 Rust 核心与 TypeScript 界面。用户授权重新选择最合适的语言。Tauri 提供 Rust 核心与 Web 界面之间的命令通信，适合把本地数据服务集中在核心侧。代价是双语言契约及平台 WebView 差异，按 S00 和 S01 验证。

ADR02 选定本地模块化单体。个人单用户使用场景以可维护和离线为主，SQLite 与托管附件形成数据基础。一个应用内通过明确服务和模块契约扩展，不引入服务器、Redis、微服务或通用插件运行时。

ADR03 选定小说模块独立重写。墨稿提供领域经验，不承担运行依赖。新系统不连接旧后端，不读写旧 MySQL，不兼容旧桌面登录与账户。用户需要历史正文时使用普通 TXT 导入。

ADR04 选定分阶段交付。S03 为独立可用的完整基础版；S04 完成非 AI 小说创作；S05 加入可选 AI 与来源规则。既有墨稿高级功能作为后续候选，不一次性重造全部能力。

ADR05 按用户 2026-10-11 要求，把 Markdown、DOCX、XLSX 和 CSV/TSV 的读取展示及生成结果归档纳入 B03/S02。它们是后续文档写作、数据收集等模块共用的平台能力。原文件为权威，结构化阅读视图为可重建投影；初次实现读取正文/表格，后续用户追加的完整编辑按 ADR06 处理。读取和字节发布都有明确容量、归属和版本边界；采集和写作业务留在模块，基础功能独立可用。


ADR06 按用户同日追加要求，所有 MD、Word、Excel 资料需可编辑，并选择接近 Office 的能力。采用 Markdown 内置编辑、本机 Office 编辑器处理 Word/Excel、平台统一版本与会话的方案。复杂格式不通过轻量阅读投影重建，提交保留编辑器保存的完整文件；图片、排版、合并、图表和重算兼容性由所选应用决定。应用内摘要阅读不冒充完整 Office 界面，发布包也不包含 Office 引擎。此方案保持 Rust/Tauri/SQLite 的本地架构，不增加在线文档服务器；未来需要内嵌 Office 时须单独选型、处理引擎许可与部署。

## 13.4 墨稿技术与业务提炼记录

| 提炼来源 | 保留的规则 | 新系统实现方向 |

新模块首版把所有提取事实设为待确认，这是对新系统复杂度的主动控制，不直接沿用旧系统自动写回政策。旧项目中的全书评分、分层生成和人物对话等，按第 4 节后续能力安排。

## 2026-10-15 接入范围修订（用户最新确认）

用户选择将同级墨稿的现有写作界面和功能迁入墨枢，使用本地 SQLite。本修订覆盖本文关于仅作领域参考、禁止复用旧前端的约束。保留写作台、短篇、素材、人物经历、完善台与上下文流程；数据、文件、备份和 AI HTTP 请求由 Rust 执行，取消旧账号、会员计费、社区与服务器依赖。同级源目录保持原样，已有墨枢手动版作品保留访问入口。按功能记录实际迁入与验证结果，未接通项不得宣称完成。

## 2026-10-17 资料库与写作空间补充（用户确认）

墨稿长篇、短篇与此前手动版作品自动进入资料库的“小说作品”阅读入口，显示最新保存正文与章节目录，可从资料库直接阅读并定位到同一章进入墨稿编辑。作品采用模块提供的只读实时投影，不复制出另一份权威正文；改名、保存、删除/恢复与完整备份恢复后的结果直接反映在资料库。停用写作模块保留已保存作品的资料库阅读，编辑仍须启用模块；模块数据故障显示明确错误。当前作品阅读条目不作为可移动、标签或收藏的普通附件副本。

进入墨稿与其他页面相同，默认保留平台侧栏、顶部横幅和正常布局，不自动全屏。点击“全屏”后进入原生系统全屏并展开写作区，点击“退出全屏”恢复普通页面；提供“返回资料库”和“返回模块中心”。切回资料库或模块中心仍通过既有保存/未保存表单/输入法保护，离开全屏写作时恢复普通窗口布局。

平台只定义通用模块资料查询、阅读和编辑定位契约；小说数据、章节顺序和正文转换留在墨稿模块。平台与墨稿 schema 均保持 4，不修改既有迁移，不新增重复正文或账号依赖。

按用户当前要求缩减主导航，选择五类固定入口与分类内页面切换，保留已有排序/固定数据。桌宠首版采用本地可替换 SVG 与 CSS 动画，暂用可爱 Q 版狐狸小女孩；不用第三方桌宠运行时、账号或网络，后续形象设计不影响窗口控制。只保存独立桌宠偏好，不让桌宠成为内容编辑器或后台 AI 代理。
