# 1 产品定位与范围

墨枢 Moshub 是一个本地优先的个人工作空间。用户在未启用任何业务模块时，也能完成项目管理、资料整理、笔记记录、任务安排、内容查找和数据备份。墨稿 Mogao 是第一个业务模块，围绕小说创作重新开发，使用平台提供的通用能力。

本文是 Codex 开发执行基线 v1.2，日期为 2026 年 10 月 11 日。产品负责人为用户，实施者为 Codex。本文中的“必须”属于交付条件；“建议”允许用有记录的等价方案替换；“后续”不计入首版验收。技术决策已按用户授权选定，待确认事项采用第 13 节的默认值，避免阻塞基础开发。

## 1.1 目标与成功条件

- 独立实用：关闭所有业务模块后，基础平台仍可完成“创建项目 → 添加资料与笔记 → 安排任务 → 查找 → 归档 → 备份恢复”。
- 长期扩展：新增内置模块主要增加模块目录、注册项和本模块迁移，不修改现有项目、资料和任务的业务实现。
- 数据可靠：所有已获得保存成功回执的内容，重启后保持完整；失败、冲突和派生分析过期均可见。
- 体验统一：基础页面与模块共用导航、主题、常用组件、错误反馈和快捷键规则。
- 按需使用 AI：未配置密钥、断网或提供商故障时，基础功能和手动小说创作仍然可用。

“持续扩展”指有清晰边界和经过验证的增加模块流程，不承诺无限数量模块或零维护成本。

## 1.3 首版范围

交付分为两个可独立验收的版本。基础版包含第 3 节全部 B 类要求；小说版在基础版上增加第 4 节 N01 至 N08。基础版可以先投入使用，小说版完成后作为第一个业务模块发布。

首版采用单用户、单工作空间、单应用实例。AI 使用用户自带连接与密钥。面向 macOS 首先验收，同时保持 Windows 构建兼容，并在小说版正式发布前执行 Windows 实机检查。浏览器开发预览只是开发工具，不等于交付 Web 版。

后续候选包括数据收集模块、文档规范驱动编程模块、云同步和更多创作辅助。首版不安排插件商店、第三方动态代码加载、账号计费、社区发布、实时协作或服务器运维系统。

## 2.2 基础平台流程

用户创建“学习计划”项目，添加两份文件和一个网页链接，建立一篇笔记并安排三项任务。资料可以同时关联其他项目，不因关联而重复复制。首页显示待办与最近编辑，搜索能跳到笔记和资料详情。完成后归档项目；归档仍可搜索和恢复为进行中。用户将数据导出为完整备份，清空测试环境后恢复，项目、附件、笔记和任务关联一致。

## 2.3 小说模块流程

用户启用墨稿，在平台项目中创建关联作品，设置简介与创作目标，添加人物、世界观及大纲，建立章节并写作。正文保存成功后可手动导出或建立版本。配置 AI 后可选择上下文并请求续写，候选在独立区域显示，采用时检查版本并保存。摘要与事实整理在保存之后执行，失败时保留正文并提供重试。

停用墨稿前先处理未保存稿件和正在执行的任务。停用后小说入口隐藏，平台项目显示保留的模块内容关联；重新启用后继续编辑。基础平台搜索可显示小说标题与停用提示，章节正文仅在模块启用时参与索引。

# 3 基础平台功能要求

所有 B 类功能都是基础版交付范围，开发顺序由第 12 节决定。基础版验收不能只检查页面存在，必须覆盖创建、修改、持久化、异常和恢复。

## 3.1 B01 首页工作台

显示最近访问项目、最近编辑笔记、今日与逾期任务、固定模块入口。支持快捷创建项目、笔记、任务，支持调整这些区域顺序和显隐。初次打开显示简洁使用引导。再次启动恢复上次有效页面；目标被删除或模块停用时回到首页并说明原因。待办提醒只在应用内呈现，首版不承诺退出软件后的提醒。

## 3.2 B02 项目管理

项目具有名称、描述、可选封面、标签、收藏状态和进行中或已归档状态。支持列表与卡片切换、按更新时间排序、关键字筛选、创建、修改、归档、恢复和移入回收站。名称必填且去除首尾空格；同名项目允许存在，以稳定 ID 区分。一个项目可关联多份资料、多篇笔记和多项任务。

项目删除先软删除项目并隐藏其关联，不删除共享资料。恢复项目同时恢复原关联。永久删除项目会清理关联记录，并把其任务转为独立任务；小说作品与项目绑定关系解除后仍保留在墨稿书架，界面提前列出影响。每个作品最多关联一个平台项目，一个平台项目可关联多个作品。

## 3.3 B03 资料管理

统一管理文件、链接和笔记，支持资料文件夹、标签、收藏、排序、筛选、移动、重命名、来源说明及关联项目。文件夹首版只管理资料，不负责平台项目层级。

文件通过选择或拖入添加，默认复制到应用管理的附件目录，记录原文件名、MIME 类型、大小和内容校验值。复制失败不创建“导入成功”的资料。去重按内容校验值识别：可复用附件字节，但保留用户独立的资料记录。删除一份资料不能移除其他记录仍引用的附件。首版文件大小上限为每份 100 MB，超限明确提示；附件按元数据和文件副本管理。

链接保存名称、URL 和说明，只接受 http 或 https，打开时使用系统浏览器；首版不自动抓取网页。文件预览支持纯文本、常见图片以及下面的文档与表格阅读，其他格式提供系统打开及导出副本。预览失败不影响资料记录。移动文件夹不能形成循环引用，删除文件夹应让用户选择移动内容或连同内容进入回收站。

### B03 文档与表格通用能力

2026-10-11 按用户要求扩充基础范围。文档、表格的读取、编辑与结果归档属于不可停用的平台能力，供后续文档写作、数据收集及其他模块复用。

| 子要求 | 必需行为 |
| --- | --- |
| B03-D01 | 导入 UTF-8 MD/Markdown，应用内展示标题、段落、列表、代码与表格；原始 HTML 作为文字，不自动执行或加载外部内容 |
| B03-D02 | 读取 DOCX 的正文段落、标题与表格，分页展示并保留原文件；明确告知未还原的 Office 格式 |
| B03-D03 | 读取 XLSX 多工作表、单元格、日期、错误值、公式文本及文件内缓存结果；保留行列位置，行列分页，未缓存结果可辨认；不执行宏、公式或外部连接 |
| B03-D04 | 读取 UTF-8 CSV/TSV 表格，保留首行、空值、引号内分隔符与换行，采集文字不被自动当成公式 |
| B03-D05 | 内置模块通过 Rust 平台接口发布生成文件及来源、说明、文件夹和项目关联；统一托管、哈希、导出与共享，不自行存储另一套附件 |
| B03-D06 | 新建和编辑 Markdown；草稿独立持久化，提交校验 baseRevision 与编辑序号；保留完整文件历史，支持导出与恢复 |
| B03-D07 | Word/Excel 接入本机 Office/WPS/LibreOffice，编辑持久副本；所选应用处理图片、复杂排版、合并单元格、图表和公式重算；保存并关闭后提交完整文件，冲突保留副本 |

2026-10-11 用户进一步要求所有文档可编辑，并选择接近 Office 的完整能力。Markdown 在墨枢内编辑与预览；Word/Excel 使用已安装的本机 Office 编辑器，墨枢托管编辑副本、提交校验及完整文件历史。复杂格式的兼容性取决于所选编辑器；当前没有在 WebView 内嵌完整 Office 界面。无需编辑器仍可使用 Markdown 编辑与文档阅读；Office 编辑需要本机对应应用，不随墨枢安装包交付 Office 引擎。

Word/Excel 流程为打开编辑副本 → 在 Office 保存并关闭文档 → 返回墨枢提交；公式重算由 Office 完成。DOC/XLS 也可通过系统关联编辑并原格式提交，平台不做二进制内容预览。新建支持 MD/DOCX/XLSX/CSV/TSV。恢复草稿和编辑会话重启后可继续，不能自动覆盖较新资料；冲突可另存独立副本。提交与恢复均建立历史版本，任何共享原件仍保持不变。平台接口也能接收模块生成字节，采集任务与 AI 写作仍由后续模块实现。

文件托管仍限 100 MiB；文档读取与生成结果发布限 20 MiB，Office 单个 ZIP 项展开限 16 MiB、总展开限 64 MiB、最多 4096 项。单元格文字限 32 KiB，工作表最多 100 张，每次读取的表格最多 200000 个单元格；DOCX 最多 20000 个正文块、单表 5000 单元格。超限、损坏或加密时明确提示并保留原文件。视图绑定资料 ID、revision 与托管哈希；失败和过期结果不得覆盖新视图。Office 编辑副本与提交沿用文件 100 MiB 上限，DOCX/XLSX 主文档部分限 16 MiB；另存独立副本通过生成接口，限 20 MiB。超限副本留在编辑会话中，可用 Office 另存到外部目录。

## 3.4 B04 轻量笔记

提供标题、正文、标签、收藏和项目关联。基础排版包含标题、段落、粗体、列表、引用、链接及撤销重做。以编辑器结构化 JSON 保存，维护纯文本索引用于搜索；导出 TXT 与 Markdown。格式转换限制应明确显示。

停止输入 1 秒触发保存，持续输入时每 5 秒尝试保存当前快照；显示未保存、保存中、已保存、失败和冲突。“已保存”只在持久化成功后出现。离开页面及正常退出前冲刷待保存内容，失败时保留恢复草稿并提供重试或明确放弃。手动保存建立可恢复版本，自动保存不无限新增版本。

## 3.5 B05 任务管理

任务包含标题、说明、未开始或进行中或已完成状态、低中高优先级、可选截止日期、可选项目关联。支持创建、编辑、完成、重新打开、删除、按状态和日期筛选；提供全部、今日、逾期和已完成视图。截止日期是本地日历日期，完成状态与逾期状态分别计算。首版无重复任务、子任务和复杂依赖。

## 3.6 B06 全局搜索

搜索项目名称与描述、资料名称与说明、链接 URL、笔记正文、任务标题与说明。按类型、项目和标签过滤，分页展示、标明命中来源，点击进入对应页面。文件附件首版搜索元数据，不搜索任意二进制正文。结果来自本地索引，不要求 AI。

中文采用可验证的规范化子串匹配作为必需基线；文本过长时分页并移出界面线程。不得仅使用默认英文分词并声称中文检索完成。后续可引入中文索引，但必须维持相同查询语义。业务数据先保存，索引异步更新；索引可从原数据重建，失败显示状态并允许修复。

## 3.7 B07 模块中心

列出随应用交付的模块及说明、版本、所需平台 API 版本、启用状态、数据占用和异常。支持启用、停用、打开模块、查看功能说明。未交付的后续模块不显示为可用按钮。第一版不提供动态下载安装或删除模块代码。

停用操作要求模块保存待编辑内容、停止本模块任务并注销导航和搜索入口；保存失败时停用失败，用户可重试或明确放弃。保留模块数据，重新启用后恢复。平台基础功能不显示在可停用模块列表。模块初始化失败只使该模块不可用，其他页面继续工作。

## 3.8 B08 外观与个人设置

支持浅色、深色和跟随系统主题，字号调整，本地昵称与可选头像，导航顺序、固定入口、首页偏好、快捷键查看及冲突检查。快捷键采用语义动作，macOS 使用 Command，Windows 使用 Ctrl；编辑器内的撤销重做优先交给编辑器。

设置立即持久化，重启仍生效。恢复默认设置只影响偏好；界面明确列出影响，不删除项目和内容。数据页显示实际存储位置与容量并允许打开目录。首版使用系统应用数据目录，数据迁移通过备份恢复进行，暂不提供任意移动正在使用的数据目录。

## 3.9 B09 回收站与备份恢复

项目、资料、笔记、任务、作品与章节采用软删除，显示类型、名称和删除时间，支持恢复和永久删除。默认不自动清空回收站。永久删除前显示依赖影响，附件仅在没有剩余引用时清理，未确定关联状态时不清理。

提供手动完整备份和每天首次成功启动后的本地自动备份，自动保留最近 7 个成功版本；失败不替代上一份成功备份。备份包含数据库一致性快照、附件、内容版本、模块数据和普通设置，排除 API 密钥、登录凭据及诊断日志。本地备份与原数据在同一设备，界面提示用户可复制到外部位置。

恢复前校验格式版本、校验值和附件清单，显示内容统计并先备份现有空间。首版恢复采用完整替换，不做自动合并；在临时目录验证后切换，失败时恢复原目录。恢复任务会阻止写入并关闭编辑会话，不能边恢复边继续写稿。详情见第 8 节。

## 3.10 B10 帮助与运行状态

提供首次引导、各功能简要说明、快捷键列表、版本与数据格式版本、最近任务状态和错误重试入口。导出诊断只包含应用版本、系统类型、错误编号及已脱敏技术信息；正文、绝对用户文件路径与密钥不进入默认诊断。加载失败有说明、重试和返回入口，不能静默出现白屏。

导入、导出、备份和分析等长任务具有进度、取消和完成结果。取消在安全点生效；取消后已提交的内容保留，未提交的临时文件清理。应用异常退出后的未完成任务标记为中断，由用户选择重试。


## 2026-10-15 接入范围修订（用户最新确认）

用户选择将同级墨稿的现有写作界面和功能迁入墨枢，使用本地 SQLite。本修订覆盖本文关于仅作领域参考、禁止复用旧前端的约束。保留写作台、短篇、素材、人物经历、完善台与上下文流程；数据、文件、备份和 AI HTTP 请求由 Rust 执行，取消旧账号、会员计费、社区与服务器依赖。同级源目录保持原样，已有墨枢手动版作品保留访问入口。按功能记录实际迁入与验证结果，未接通项不得宣称完成。

## 2026-10-17 资料库与写作空间补充（用户确认）

墨稿长篇、短篇与此前手动版作品自动进入资料库的“小说作品”阅读入口，显示最新保存正文与章节目录，可从资料库直接阅读并定位到同一章进入墨稿编辑。作品采用模块提供的只读实时投影，不复制出另一份权威正文；改名、保存、删除/恢复与完整备份恢复后的结果直接反映在资料库。停用写作模块保留已保存作品的资料库阅读，编辑仍须启用模块；模块数据故障显示明确错误。当前作品阅读条目不作为可移动、标签或收藏的普通附件副本。
