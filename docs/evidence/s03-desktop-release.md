# S03 桌面收尾、故障恢复与本地 Release

日期：2026-10-13。本轮仍只完成基础平台，不实现小说、AI 或采集业务。本文件补充 S03 原有证据；用户手动报告、工具观察、核心测试和安装包检查分别注明。

## 桌面流程

使用 `.tools/s03-foundation` 隔离空间，未用生产空间进行故障注入。

- 原生文件选择导入 `封面验证.png`，资料显示 MIME/字节数/哈希；滚动到详情，图片真实渲染。
- 从项目封面选择器选中该图片，保存后显示项目封面；头像原生选择导入后，侧栏显示个人头像，重启保持。相同图片字节可复用 blob。
- 在该隔离库安装临时 SQLite 触发器，拒绝更新笔记。正文输入后快捷保存返回 DB_ERROR，输入保留；原数据库未包含本次修改，带校验的恢复草稿已落盘。
- 关闭窗口显示“恢复草稿已落盘”确认，初始聚焦取消。取消后正文完整。再次关闭、移除测试触发器并重启，原稿保持；首页可对照恢复本次输入，以当前 revision 合并后成功保存并建立原稿快照。测试触发器已移除。
- 实际按键撤销及 Command+S 保存通过。用户按提供步骤手动验证：简体拼音连续输入两段中文，穿插 Command+S，再切首页并返回；用户报告没有丢字、未完成拼音被保存、光标异常或快捷键误触。此项是用户手动证据，不是自动输入法测试。

Finder 拖拽工具两次返回 noWindowsAvailable，访问系统输入源菜单超时；不记为自动桌面通过。系统设置只读显示已安装 ABC 与简体拼音，未由代理改动系统配置。用户随后手动拖入“拖入验证.md”，报告可以找到并打开；只读核对隔离库新增1条该文件记录，托管字节与验收源文件逐字节相同，大小与SHA-256一致。1440×900/系统缩放所需显示环境当前无法调整，继续待验收。

## 修复与真实故障测试

恢复切换增加 Unix 目录同步：暂存树、未提交日志、目录重命名、回退及清理都在适当顺序同步。已发布的提交记录之后发生同步/清理错误，不会错误报告“已回滚”；旧副本在提交记录目录同步成功之前保留。其他平台仍需独立验证目录持久化，不承诺真实断电结果。

`src-tauri/tests/recovery.rs` 新增一个实际进程中断测试及一个辅助入口：子进程调用真实 snapshot/inspect/replace，父进程锁住暂存新库，使新库初始化停在可观察位置；四个目录已切换、恢复日志未提交时结束子进程。重启调用真实 Database::open，原空间最新已确认正文与目录保留，恢复日志清理，原备份仍在。不是手工造一份日志代替实际切换，也不是硬件断电测试。

v2→v3升级新增真实旧库测试：核对成功升级保留工作空间和笔记，同时ZIP保留完整v2原稿；制造迁移表冲突后，升级失败仍保持v2和原稿，新增dirty表回滚，升级前备份仍存在且可读取原稿。

备份改用 64 KiB 分块读取、哈希与 ZIP 写入，限制总量和项数，减少按整份文件分配的峰值内存；文件内部安全点支持取消，未完成包不发布。新增 8 MiB 实际文件测试，在文件处理过程中取消，核对源文件不变、目标包不存在；正常备份检查和恢复的全部字节一致。

资料目录订阅原生 file-drop-result 成功事件，立即刷新当前筛选目录并保留未提交详情字段；项目资料会更新封面选择器。组件回归覆盖事件刷新、筛选保持、未提交名称和解除订阅；组件事件替身不等于Finder实机拖拽证据。随后重开最新构建并停留资料库，用户再拖入同一验收文件，报告列表立即出现独立新记录、不需要切页；只读核对新增第二条记录。

## Release 核心性能

硬件 Mac17,3、10 个物理核心、16 GiB 内存、arm64；macOS 27.0.1。使用优化后的核心例程、实际 SQLite/事务与真实 ZIP；测试数据为100项目、10000链接资料、1000笔记、5000任务（笔记另含资料记录，超过要求的资料数量）。不包含 Tauri IPC、WebView、冷启动或页面切换时间。

| 测量 | 样本与结果 |
| --- | --- |
| 规范化中文/名称/任务/空结果搜索 | 50 次，p95 4.23 ms |
| 保存后需要重建投影的搜索 | 20 次，p95 77.17 ms |
| 10000 字符笔记保存，含部分手动版本 | 50 次，p95 0.44 ms |
| 全量投影重建 | 62.27 ms |
| 数据库完整备份 | 171.38 ms；该基准没有大附件 |
| 数据库重开与状态读取 | 39.92 ms；不等于原生冷启动 |

原始结果见 `foundation-benchmark.json`。复现：

```sh
npm run rust -- run --manifest-path src-tauri/Cargo.toml --release --no-default-features --locked --example foundation_benchmark
```

核心搜索/保存指标满足目标，AC23 整体不关闭；仍须原生10次启动、50次页面切换、长文交互及对应容量实测。没有降低目标或将构建大小当作速度。

## 工程与安装包

Rust fmt、strict clippy、default/no-default-features 两套测试通过；每套68个入口中64个为业务断言、4个为辅助入口，默认忽略1个显式系统凭据探测。前端 strict、ESLint、40个测试及生产资源构建通过。

新增 `npm run release:local`：macOS 使用 Tauri 构建 Release app/DMG，并用 signingIdentity=- 对整个 bundle 作本地 ad-hoc 签名。不使用个人证书或系统凭据，不上传。最初仅有链接器签名的 bundle 未通过 strict 校验，已修正整个 bundle 的签名和资源封装；最终 codesign --verify --deep --strict 与 hdiutil verify 均通过。Release app 18.74 MiB、DMG 5.80 MiB；应用包大小19654209字节、DMG大小6078839字节，SHA-256为 d6efea928a205eb077e2907aa1aa41aa20d9549d28b01bb3acb0986a78d6a9e0；结构化记录见 local-release.json。最新Debug app 51.81 MiB，主JS332.02 kB、编辑器405.48 kB、CSS24.58 kB（未压缩）。

当前不是 Developer ID 签名和公证的公开分发版；未执行 Windows实机或 Microsoft Office/WPS兼容测试。实际Release安装后的原生冷启动与页面延迟也仍待测，不以包生成替代运行验收。Windows环境与公开签名凭据尚未提供。
