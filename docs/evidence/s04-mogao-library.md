# 墨稿作品资料库与完整窗口写作

日期：2026-10-17。用户要求墨稿小说进入资料库并从资料库查看，进入墨稿时使用更大的写作空间；最新明确要求“点击墨稿也和点击别的一样”，默认普通页面，通过按钮选择进入或退出全屏。

## 行为与范围

资料库自动收录墨稿长篇、短篇及此前手动版作品；无需手动导出再导入。条目提供名称/简介搜索、作品分页、字数、章节数、目录阅读、最新保存时间、所读章节版本及“进入墨稿编辑”。进入编辑定位到所读作品与章节，返回资料库先冲刷原有编辑器并读取新稿。

阅读条目由模块发布只读实时投影，原稿仍由墨稿持有，不创建另一份权威正文或文件副本。删除的作品/章节不显示，恢复后再次可读；停用写作模块仍可在资料库阅读，编辑入口显示禁用。已有普通文件、链接、笔记和项目资料功能保持可用。小说条目暂不参与普通附件的文件夹、项目、标签、收藏筛选，界面和 README 明确说明；这轮不增加小说元数据整理或附件副本同步。

进入模块默认保留平台侧栏、横幅和正常布局，提供“返回资料库”“返回模块中心”“全屏”入口。点击“全屏”才进入原生系统全屏并展开写作区，隐藏外层侧栏、横幅和页面留白；点击“退出全屏”恢复普通布局。此前手动版继续使用同一空间，溢出内容可滚动。基础平台页面保持正常导航。视图改变不绕过保存、版本冲突、输入中或未保存表单保护。

## 分层和数据

新增通用 `ModuleLifecycle::library/read_library`，平台服务和静态命令 `list_module_library/read_module_library` 只处理注册模块、查询、分页、读取与错误。作品选择、章节归属/排序、HTML 到保留段落的纯文本和编辑定位由墨稿模块提供。平台不查询小说业务表，不把小说规则写入普通资料 SQL。

UUID、支持的作品种类、章节归属和软删除在 Rust 校验；目录和选中正文处于同一数据库快照，旧请求不会覆盖前端新选择。一次仅返回选中章正文，目录只含元数据。阅读不修改正文、来源哈希、revision 或 AI 状态。模块故障显示警告或明确读取错误，普通资料不受影响。

平台与模块 schema 保持 4，完整备份格式保持 1，不修改既有迁移。已有作品直接可读，完整备份恢复后从原表重读，不需要迁移或重建重复资料。系统窗口只新增查询/切换原生全屏的权限；文件和密钥边界不变。

## macOS 桌面实测

使用 Debug 应用与 `.tools/s04-mogao` 隔离测试空间，未修改同级原墨稿或向日常作品注入测试内容。

1. 最新构建中点击侧栏“墨稿”，默认保留平台侧栏、横幅、运行状态和正常页面留白，按钮为“全屏”；写作台正常呈现既有作品，未自动展开或进入系统全屏。
2. 点击“全屏”，按钮变为“退出全屏”，系统窗口进入全屏，侧栏与横幅隐藏、写作区展开；再次点击恢复普通窗口、侧栏和横幅。另一次在全屏中点击“返回资料库”，同样正常退出全屏并恢复普通资料库页面，未遇权限错误。
3. 点击“返回资料库”，普通导航恢复；小说作品区直接显示 5 本既有作品，包括新长篇、两个独立短篇和两本此前手动版作品，章数与字数为真实数据。
4. 在资料库打开“墨稿迁入 · 远山”，显示“第一章 北城”及两段正文、24 字、已保存版本 2。点击“进入墨稿编辑”，原写作台路由定位到同一作品与同一章。
5. 追加“资料库会显示这次保存的新段落。”，直接点外层“返回资料库”，回到原作品阅读页，新文字立即可见；字数为 38，版本为 4，保存时间更新。未另行导出文件或刷新页面。
6. 打开此前手动版“分章验证作品”，目录为“序章 / 第一章 出发 / 第二章 归来”；切到归来显示“他终于看见故乡的渡口。”。从该阅读页进入编辑，旧手动版打开同一章、版本 1、11 字，输入稿未被替换为新模型。

中文使用粘贴核对内容，不能据此关闭完整拼音输入法验收。当前窗口及 macOS 原生全屏通过，不扩展宣称 Windows、所有缩放与屏幕尺寸、长篇容量或全键盘组合已验收。
