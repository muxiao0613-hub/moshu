# S04 墨稿手动小说版证据

日期：2026-10-15（Asia/Shanghai）。用户明确授权加入墨稿；本轮为 N01–N04，未加入 S05 的 AI、候选采用、来源提取或上下文。基础版的 Windows、系统缩放等原有待验收项继续保留。

## 交付与边界

墨稿为可信编译内置模块，默认停用。模块中心启用后，首页和侧栏提供入口；平台的项目、资料、笔记、任务、搜索、设置、回收站和备份仍独立使用。小说数据仅在 `src-tauri/src/modules/mogao` 定义，前端位于 `src/modules/mogao`。未读取或修改相邻旧墨稿项目，没有复制旧实现或迁移账号/旧库。

平台 schema=4，墨稿 schema=2，正文 schema=1，完整备份格式=1；历史迁移未修改。新增平台通用模块引用表及公开事务接口，墨稿通过该接口引用项目、封面和资料。恢复前在暂存空间迁移/校验模块，成功切换后同步启停；失败保留原工作空间。启用前重新验证模块，初始化故障隔离为模块错误。

## 真实 SQLite / 文件测试

`src-tauri/tests/mogao.rs`：13 个测试，以临时工作空间、真实 SQLite、触发器故障、真实 ZIP 和实际字节执行，不以源码字符串作为验收。

| 测试主题 | 实际断言 |
| --- | --- |
| 保存/版本/归属/重开 | 同 baseRevision 两次保存恰有一次成功；跨作品读取拒绝；Rust 生成文字及字数；手动前后快照、恢复新 revision；释放并重开数据库后内容保留 |
| 恢复稿与另存 | 旧序号不覆盖新稿，旧回执不清理新稿，不同会话不得覆盖；注入快照失败时新章和草稿整体回滚；成功另存保留原章 |
| 卷章目录 | 稳定 ID、跨卷移动与目录顺序、状态、过期 treeRevision 拒绝；外作品卷不可使用；删除/恢复章节仍保留大纲关联；非空卷不可删除 |
| 创作设定 | 同作品人物结构关系；跨作品关系拒绝；父子大纲循环和非空父节点删除拒绝；每次有效写入增加设定版本；计划不写入正文 |
| TXT 与输出 | UTF-8 BOM/中文三章、单章降级、非法编码、20 MiB 超限；第二章写入故障导致作品整体回滚；TXT 和指定章 Markdown 按目录排序 |
| 完整备份恢复 | 真实备份恢复正文、版本、恢复稿、设定；运行时启停重新同步；停用时基础项目仍可写入 |
| 项目/资料引用 | 永久删除项目只解除作品关联；仍被设定引用的资料不可永久删除，删除影响包含模块引用 |
| 全局搜索与回收 | 正文中文命中携带真实模块/作品/章节 ID；停用只搜作品名；全局恢复正文、删除设定、永久删除作品与下属版本 |
| 继续位置/结构化备份 | 保存章节位置；已删除章不再自动打开；JSON 含软删除章节、正文、历史和恢复稿 |
| 未来模块备份 | 未来墨稿迁移版本在切换前拒绝，当前作品保留，基础笔记继续可写 |

| 恢复旧基础备份 | 无墨稿的基础备份恢复后，基础笔记保留，墨稿运行时停用；再启用为空模块 |
| v3 平台升级 | 真实构造旧版 v3 校验迁移，升级至 v4 后工作空间 ID/已有正文保留，升级前保护备份已建立，墨稿默认停用 |

## 前端行为测试

`tests/mogao-ui.test.tsx` 使用真实 Tiptap 和 SaveSession，只替换 IPC；jsdom 几何接口补充不代替原生桌面。

1. 保存使用所属作品和不可变快照；旧回执保留保存期间新输入的“未保存”状态，清理只通过对应序号。
2. 切章先保存；写入失败留在原章，正文/标题保留。
3. 恢复稿先让作者选择；未确认前不写正文、不覆盖恢复稿；选择后进入对照合并状态。
4. 专注、行距和查找不制造保存；真实编辑器查找选区正确。
5. 输入后打开目录调整会先保存，调整使用保存后的章节 revision，避免以旧元数据覆盖新输入。
6. 段落查找可跨粗体等格式边界定位完整短语，不制造保存。

前端累计 46 项通过，严格 TypeScript、ESLint 和生产构建通过。模块代码分块加载，平台启动不预加载小说编辑器。

## macOS 原生操作

Debug 使用独立 `.tools/s04-mogao` 工作空间；未对用户已有工作空间做故障注入。默认窗口 1280×800（Retina 截图为双倍像素），不据此声称大窗口/系统缩放通过。

- 模块中心显示墨稿，启用变为 ready，侧栏出现固定入口；内容统计为真实文本字节近似值。
- 创建“长河入海 · 桌面验证”，保存名称、类型与简介；新建两章，第一章粘贴两段中文并 Command+S，版本 2、31 字。
- 继续输入“他把地图收入行囊。”后立即切到第二章，再返回，第一章为版本 3、40 字，三个段落全部保留。
- 保存人物“林舟”的目标和作者固定设定，设定版本 1→2；保存“启程计划”并关联第一章，版本 2→3。界面明确标示大纲为计划。
- 平台搜索“钟声”命中第一章，点击返回同一作品和正文。
- 原生选择 `inputs/分章验证.txt`，预览正确识别“序章 / 第一章 出发 / 第二章 归来”；确认后整本作品三章可见，字数为 7/13/11。
- 原生导出 Markdown 到隔离目录，读取实际输出字节，确认标题、正文及章节顺序逐字一致。
- 历史版本显示 1/2，恢复版本 2 得到当前版本 4、31 字；再次查看历史，版本 3（40 字）仍保留，恢复后当前版本 5、40 字。专注模式正常展示，Escape 退出。
- 创建“第一卷 山河”，将第一章移入卷中，当前章版本 6；正常关闭并重启后，第二章仍在不分卷，第一章仍在新卷，版本 6、40 字和完整正文保留，自动返回该章。
- 停用墨稿，模块保留内容统计，项目页可用；重新启用后回到同一卷、章节及正文。

中文粘贴验证不等于墨稿内完整 IME/选区/快捷键组合验收；此前基础笔记的用户手动 IME 报告不扩大为本轮全部组合通过。
