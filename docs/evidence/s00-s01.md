## macOS 真实窗口操作

使用 Debug app，隔离数据目录 `.tools/desktop-smoke`，没有将展示数据预置到应用首页。

1. 打开项目页，创建项目；列表出现真实记录及归档/添加笔记操作。
2. 从项目创建关联笔记，打开实际 Tiptap 编辑器，初始 revision=1。
3. 通过系统剪贴板输入标题“中文保存验证”和两段中文正文，点击“保存并建立版本”。窗口显示“已保存”、revision=2，列表标题同步。
4. 切换首页，项目和笔记数量均为 1，最近笔记可打开。
5. 关闭原进程，使用同一个隔离目录重新启动；首页数量仍为 1/1。打开笔记，标题与两段中文正文完整，revision=2。
6. 在正文末尾立即添加中文段落后关闭窗口；关闭前保存回调完成。只读检查隔离数据库：revision=3，新段落保留，project_resources 关联数=1，手动快照数=1。
7. 最终构建再次启动同一隔离目录：打开 revision=3，正文含关闭前新增段落；手动保存后为 revision=4；选择第一段并应用粗体后保存为 revision=5，窗口显示“已保存”，JSON 粗体格式已写入真实数据库。

界面截图与 AX 状态已在本次操作工具结果中核验。测试工具的 typeText 没有输入预期汉字，改用系统 paste 成功；该事实不足以判断真实拼音输入是否正常。因此系统中文 IME 连续组合输入、选区及快捷键冲突仍明确待验证。
