# S02 项目与资料子任务证据

日期：2026-10-11。环境沿用 S00：macOS 27.0.1 / Apple Silicon、Node 24.12.0、Rust 1.99.0、Debug 构建。范围为 B02 与 B03 的项目/资料子任务，关联 AC02、AC03、AC05、AC09、AC24、AC25；不代表 S02 整体完成。

## 实现

项目：创建与详情编辑、收藏、标签、图片附件封面、归档/恢复、移入回收站与当前详情撤销、卡片/列表、文字/状态/标签/收藏筛选和分页。

资料：文件/链接/笔记统一元数据、重命名、来源说明、文件夹、标签、收藏、筛选分页、多项目关联与解除、软删除与撤销。笔记重命名同时推进笔记 revision，旧编辑稿会遇到冲突。

文件：Rust 原生选择 → 阻塞线程复制到同目录临时文件 → SHA-256 → 同步落盘及不覆盖发布 → 短数据库事务提交资源与关联。重复内容共用 blob，保留独立资料记录；导入串行锁防止一个失败导入删掉并发成功导入的附件。事务失败清理未引用的新附件，异常退出产生的暂存/孤立附件在下次启动清理。不存在“先显示成功、再复制”的路径。

预览只返回受限文本或图片 data URL；系统应用打开临时副本，导出使用已选原生目的路径及同目录原子发布。UI 不接受任意读写磁盘路径，不持有 blob 内部路径。读取、打开、导出前校验 SHA-256 和大小；缺失或损坏附件保留资料记录并报错。
