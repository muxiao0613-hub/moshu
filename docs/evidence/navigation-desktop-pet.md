日期：2026-10-17。按用户新要求归纳页面，并先采用可爱的 Q 版狐狸小女孩占位形象，后续单独细化设计。本功能属于本次明确新增范围，不表示此前小说 AI 或跨平台验收已经完成。

## 分层与数据边界

新增通用桌宠契约和平台配置服务。`platform_preferences` 的 `desktopPet` 键含 revision、enabled、alwaysOnTop、size；缺失时默认关闭。短事务和 baseRevision 检查复用平台数据约定，平台与墨稿 schema 保持 4，无新增迁移或依赖版本。个人偏好和桌宠偏好各自独立修订。

`get_desktop_pet` 返回持久设置与实际窗口显示状态；`save_desktop_pet` 保存后应用原生窗口；`pet_action` 只接受打开主窗口、收起和找回三个语义动作。配置保存成功但原生窗口失败时明确报错，页面重读配置并提供重新显示。重启时自动恢复已启用的桌宠，启动窗口失败不阻断主工作空间。

透明窗口由 Rust 创建固定 label 和固定本地 URL，不开放前端任意窗口创建、路径、URL 或 SQL。桌宠 capability 不授予通用原生窗口权限；自定义命令入口按真实调用窗口标签限制桌宠仅查询桌宠状态、执行桌宠动作和有界拖动，正文、导出、AI 和任意设置写入均拒绝。拖入文件只由主窗口处理。所有内容编辑仍只在主窗口，桌宠退出不会直接结束编辑器。

本地 SVG 可独立替换；眨眼、呼吸、摇尾和摸摸动画支持 reduced-motion。暂不提供自定义形象导入、跨屏拖动、桌面漫游、自动对话、主动提醒或开机自启。收起不会退出整个墨枢，退出墨枢会一并关闭桌宠。位置不跨重启保存，重新显示在当前屏幕内落位；“找回桌宠”可复位。完整备份恢复后的配置在下次启动或重新设置时应用。macOS 透明窗使用 Tauri 2.12.3 的 macos-private-api feature，本轮为本地 ad-hoc 交付，未声明 App Store 兼容或公开公证完成。

## macOS 实机记录

使用 Debug app 和项目内 `.tools/s04-mogao` 隔离数据，未修改原墨稿或日常工作空间。

- 侧栏实际只显示首页、工作、资料、创作、工具五个按钮。实际切换工作内的项目/任务、资料内的资料库、创作内的模块管理/墨稿和工具内的桌宠；墨稿仍普通页面打开，保留全屏按钮。工具分类显示五个二级入口，资料库仍列出原有五部真实测试作品。
- 在工具的桌宠页开启，实际创建“墨枢 · 小狐狸”独立无边框窗口；Q 版形象、气泡、菜单和收起按钮完整可见，标准/小号窗口均检查，无界面裁切。
- 点击摸摸显示反馈与爱心；菜单休息显示闭眼与 z 字，唤醒正常；返回墨枢实际切回主窗口；收起后主页面状态立即更新为未开启，可再次显示。
- 小号和关闭置顶偏好已实际设置。主窗口正常关闭后应用进程退出，桌宠没有单独驻留。

原生 startDragging 在本机出现系统警告且坐标未变化，因此改用指针捕获与受控 Rust `pet_drag`，严格按会话顺序更新固定窗口物理位置，不使用任意窗口控制能力。最终构建开启专用 Debug 坐标探测后，拖动使原生窗口位置从 (2492,1196) 变为 (2412,1096)，真实位置变化且无系统拖动警告；“找回桌宠”可复位。重启后自动创建小狐狸窗口，主页面读到之前的小号和关闭置顶设置；随后重新启用置顶。该探测仅在显式 MOSHUB_DEV_PET_TRACE=1 的 Debug 验证中输出窗口坐标，正常运行与 Release 不输出。本轮不声称 Windows、所有显示缩放、多显示器边缘、系统 Spaces 或所有输入法组合已验收。
