## macOS 实机

使用项目内隔离空间 `s02-desktop`，保留此前两个项目和两份资料。任务数据库起初为空，操作真实 Debug app：

1. 创建“本地今日任务”，中文说明、高优先级、截止日 2026-10-11，关联“S02 学习项目”，收到 revision=1。
2. 今日视图出现任务；完成后 revision=2，已完成视图出现且没有逾期标记；重新打开 revision=3，从已完成视图退出。
3. 编辑截止日为 2026-10-10，点击主导航任务入口触发离开前保存，列表显示新日期及逾期，revision=4；逾期视图包含该记录。
4. 完成后 revision=5，立即退出逾期视图；已完成视图保留日期及项目，但不标逾期。
5. 初次删除实测发现 WKWebView 未显示 window.confirm、操作未继续。改为应用内确认并重建，重新启动显示原 revision=5。点击“确认移入回收站”后显示成功和撤销入口，随后撤销恢复 revision=7，状态、优先级、日期和关联未丢失。
6. 项目详情显示任务摘要，点击项目任务入口打开带该项目筛选的任务页；重新打开任务至 revision=8，显示未开始和逾期。
7. 空白新任务正确显示“尚未创建”；输入临时标题后返回列表显示应用内放弃确认。显式放弃后没有新增记录，原任务保留。
8. 正常关闭并重启，任务页仍显示 revision=8 对应的状态、优先级、截止日和项目。只读 SQLite 核对：仅一条任务，due_date=2026-10-10、status=notStarted、priority=high、deleted_at=NULL、项目 ID 一致；原两份资料仍在，quick_check=ok。

任务删除仅软删除，当前编辑器可撤销；退出后恢复入口要等 S03 完整回收站。任务尚未提交的字段没有笔记式持久恢复草稿，正常切页/关闭先保存，失败保留输入；异常退出的未提交任务字段不作恢复保证。
