# 墨枢项目速览（给接手的 AI）

更新：2026-10-21。这是一张导航图，不是规范。与六份主题文档冲突时以主题文档和代码为准；与本文件冲突时以代码为准，并顺手修正本文件。

## 1. 三十秒理解

墨枢（Moshub）是一个**本地优先的桌面个人工作空间**，Rust + Tauri 2 + React + SQLite。它有两个部分：

1. **基础平台**：项目、资料（文件/链接/文件夹/阅读/文档编辑）、笔记、任务、中文搜索、模块中心、设置、回收站、完整备份、帮助与脱敏诊断。不依赖任何业务模块也能完整使用。
2. **墨稿**：内置小说创作模块。既有手动版（Tiptap，`src/modules/mogao`），也有从同级旧墨稿迁入的完整写作台（`integrations/mogao`，React 18 独立构建，通过同源 iframe + `postMessage` 桥接 Rust）。两者数据**不自动合并**。

没有账号、没有云同步、没有远程后端；AI 是可选连接，密钥用系统凭据或会话内存，不落库。

## 3. 跑起来与验证

```sh
npm ci && npm ci --prefix integrations/mogao
npm run tauri -- dev          # 真正的桌面应用（需要 Rust 工具链）
npm run dev                   # 仅浏览器预览，无 Rust 桥接，会明确报本地数据不可用
```

```sh
npm run typecheck
npm run lint
npm test                                                  # vitest，已配置 vmThreads
npm run build                                             # 先构建墨稿，再 typecheck + vite build
npm run rust -- fmt --manifest-path src-tauri/Cargo.toml --check
npm run rust -- clippy --manifest-path src-tauri/Cargo.toml --all-targets --locked -- -D warnings
npm run rust -- test --manifest-path src-tauri/Cargo.toml --locked
npm run rust -- test --manifest-path src-tauri/Cargo.toml --no-default-features --locked
```

- `scripts/rust.mjs` 与 `scripts/tauri.mjs` 会自动使用项目内 `.tools/cargo`、`.tools/rustup`，不改全局 shell。
- 桌面实测可用 `MOSHUB_DEV_WORKSPACE=<目录>` 指定隔离工作空间（Release 忽略）；`MOSHUB_DEV_PET_TRACE=1` 才输出桌宠窗口坐标。
- 真实系统凭据测试是显式 `--ignored` 探测，使用随机项并在读取后删除。

## 5. 架构与硬规则

依赖方向单向：**界面 → 命令契约 → 应用服务 → 领域与持久化**。领域层不依赖 UI。

- 前端**不持有**任意 SQL、磁盘路径或明文密钥；所有 IO 走 Rust 命令。
- 平台**不含**小说业务规则；平台通过 `ModuleLifecycle` 的 `library/read_library` 等接口拿投影，不查小说表。
- 写入必须：参数化 SQL、短事务、归属校验、`baseRevision` 比较；零行更新即冲突。
- AI 内容先进入候选，采用时校验版本、建快照、幂等提交；正文安全保存后才做派生分析。
- 备份不含密钥；日志与诊断不写用户正文、密钥、绝对私有路径。
- 基础功能不可停用，不依赖墨稿；墨稿关闭时平台照常可用。
- 不引入微服务、服务容器、动态插件运行时；不提前实现后续阶段能力。

## 6. 数据与可靠性（骨架）

- **单库单写线程**：`mpsc::sync_channel(32)` 串行执行；`fs2` 独占文件锁保证单实例；`busy_timeout=3s`、`journal_mode=WAL`、`synchronous=FULL`。
- **迁移**：每条记录 SHA-256 校验；启动 `PRAGMA quick_check` + `foreign_key_check`；拒绝未来版本与被篡改迁移；v1–v3 升级前自动建完整备份。
- **乐观并发**：所有更新带 `baseRevision`；`SaveReceipt` 带 `clientEditSequence`，迟到回执不会把新输入标成已保存。
- **草稿**：笔记/Markdown 正文每 2 秒由 Rust 原子落盘；保存回执只清理 ≤ 确认序号的草稿；切页/关闭前冲刷。
- **版本**：笔记、章节、托管文件都有不可变快照，恢复旧版产生**新** revision。
- **备份**：`.moshub.zip`（manifest + 一致性快照 + 附件 + SHA-256）。恢复流程是「校验 → 临时目录 → 迁移校验 → 备份当前 → 原子切换」，失败回退。
- **搜索**：平台投影表 + 中文子串匹配，重建可取消。

表分组（详见 `docs/data-dictionary.md`）：`platform_*` 为平台（项目/资料/文件夹/标签/笔记/版本/任务/偏好/会话/任务队列/模块状态/链接/搜索/迁移/元信息），`mogao_*` 为小说（作品/卷/章/版本/草稿/设定/位置/写作台实体/版本/回执/AI 运行）。

## 7. 命令与窗口边界

- 每个命令输入带 `requestId`；错误统一为 `AppError { code, message, retryable, requestId, details? }`，前端用 `asAppError` 展示。
- 窗口鉴权在 `commands::pet::command_allowed`：主窗口可调全部；`desktop-pet` 窗口只允许 `get_desktop_pet`、`pet_action`、`pet_drag`；其他标签一律拒绝。
- 桌宠窗口没有通用原生窗口/文件系统权限，capability 只给 `core:event:default`。
- 桌宠退出由主窗口 `Destroyed` 事件触发；关闭桌宠窗走 `CloseRequested` → `pet_action(hide)`。

## 8. 前端要点

- `App.tsx` 持有启动状态、当前 `Page`、偏好与错误；页面用三元表达式直接渲染（密度高，改动时注意保存保护）。
- `shared/lib/bridge.ts` 是唯一命令入口；浏览器环境没有 Tauri 时给出明确错误，不用假数据。
- `shared/editor/save-session.ts` 负责输入序号、串行保存、冲突与草稿；改编辑器前先读它。
- 五类主导航在 `app/navigation-groups.ts`：首页/工作/资料/创作/工具；二级页面仍在同一 `Page` 路由内切换。
- 迁入墨稿通过 `IntegratedWorkspace.tsx` 加载 iframe；桥接只暴露白名单路由，`requestId` 幂等，同 ID 不同载荷拒绝。

## 9. 墨稿模块现状

- 手动版：`MogaoWorkspace` + `ChapterEditor`，Tiptap JSON → Rust → SQLite。
- 迁入版：`studio/`（Rust）对应原界面路由语义 API，正文变更前自动快照，来源引用逐字校验并标记失效。
- **已知短板**：N06「候选原子采用」（校验版本 + 快照 + 同事务 adopted 标记）与 N08「Rust 上下文编译器」未完成；真实 AI 提供商未验收。

## 10. 桌宠（2026-10-21 状态）

- 独立透明无边框窗口，label `desktop-pet`，尺寸小 200×270 / 标准 240×324 / 大 288×388。
- 拖动：指针捕获 → `pet_drag(start/move/end)`，Rust 按当前显示器 `scale_factor` 换算物理坐标，支持跨屏；松手/恢复时投影到最近实际显示器，避免停在错位多屏间隙。
- 位置：拖动结束与「找回桌宠」写入 `platform_preferences.desktopPetPosition`（物理坐标，独立于设置 revision），启动/重新显示恢复；损坏或越界按无记录处理。
- 名称南华；20 动作 / 140 帧，Canvas 时间轴与姿态队列衔接阅读、睡眠和互动；窗口隐藏暂停，系统「减少动态效果」时停帧。
- 素材：`src/platform/pet/assets/motion/*.webp`，20 张透明图集约 15.8 MiB；manifest 记录提示词和帧参数，旧六张 PNG 与 SVG 保留作回退。源码、素材与校准脚本一并纳入本轮版本控制。
- 交互：单击摸摸、双击返回墨枢、右键/「···」菜单（返回、休息、坐起、招呼、阅读、左右走、收起）。macOS 已实测，Escape 无焦点关闭已修复。
- AC32 部分通过：已取消全人物叠影并校准 140 帧头部轮廓锚点与脚底基线，同帧不重绘；浏览器五秒样本中绘制调用减少约 94%–96%。脸型、服装细节仍有差异，WKWebView 帧时长、Windows、多屏、系统缩放及减少动态效果实机仍待验。

## 12. 常见坑

1. **`npm test` 的环境**：jsdom 每个文件创建成本高，已用 `pool: 'vmThreads'` + `tests/setup.ts`（`asyncUtilTimeout=5000`）。不要移除，否则笔记编辑器懒加载会制造「假红」。
2. **Rust 有两套配置**：默认含 Tauri（桌面），`--no-default-features` 为核心。只跑一套会漏。
3. **历史迁移不可改**：只能追加新迁移并更新校验和；升级旧库会自动先备份。
4. **图片素材**：20 张 WebP 为主动画，6 张 PNG 是真实加载失败回退资源；不要当作测试图片删除。
5. **`App.tsx` 与 `studio/mod.rs` 密度高**：改动前先跑保存保护与桥接测试。
6. **不要碰同级旧墨稿目录**，也不要恢复对旧后端/MySQL/账号的依赖。
7. **凭据探测**是 ignored 测试，正常运行不会读用户已有凭据。
