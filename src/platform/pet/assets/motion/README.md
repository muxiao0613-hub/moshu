## 来源与制作方式

所有动作绘制使用内置 imagegen，不使用 CLI/API 密钥，不用程序复制静态姿势冒充新动作。最终采用的逐动作提示词、帧数、播放速度、画布规格和文件名记录在 [manifest.json](manifest.json) 的 clips 中。生成图使用统一的暖橘长发、琥珀眼、狐耳大尾巴、墨绿奶白服装设定；参考图编辑请求多次连接失败后，最终图集按统一文字设定生成。

`scripts/package-pet-motion.cjs` 仅机械切分生成图、以动作内统一比例缩放、按全部轮廓并集保留水平边距、对齐脚底基线、补透明边距并重新排版为图集；不创作动作或补造中间帧。运行脚本需要现有 Sharp，可通过进程环境变量 `MOSHU_SHARP_MODULE` 指定模块位置；未安装新依赖或修改全局 shell 配置。输入为 stdin JSON，包含 id、path、prompt。原始生成 PNG 保留在图片工具的生成目录，应用只引用本目录内的图集。

## 播放与衔接

- 主播放器用 Canvas + requestAnimationFrame，以经过时间选择帧；解码完成前保留上一画面，不在 React 中逐帧 setState。
- 当前动作解码后复用；下一动作提前解码。LRU 解码缓存按 32 MiB / 最多 8 项约束，同 URL 共用进行中的解码，不一次展开全部 140 帧。
- 只绘制一张完全不透明的姿态，取消原先帧末与动作切换时的全人物叠加，避免双眼、双耳重影。同一源帧不重复清屏和绘制；稳态微呼吸由轻微合成层缩放承担，随隐藏和减少动态效果暂停。
- registration.json 记录每帧绘制变换和对应 WebP SHA-256。离线校准头部轮廓横向锚点、脚底基线和透明边距，不改写原图像素。源图变更后运行 scripts/calibrate-pet-motion.cjs 更新参数；哈希回归测试拒绝过期校准。
- 阅读链为坐下 → 拿书打开 → 坐着阅读 → 定期翻页 → 合书 → 起身；睡眠链含坐下、犯困、蜷尾睡觉、揉眼醒来；短暂互动结束回到之前的持续状态。
- 左右走动通过菜单主动触发，沿用有界原生拖动命令；拖动合并尚未发送的位置，防止积压过时指针事件。
- 隐藏窗口暂停帧计时；减少动态效果时不播放帧动画。旧 PNG/SVG 仅作为素材加载失败时的回退。
- 设置页展示 20 个动作，重复点击同一动作可从头预览；不改变原生桌宠的当前状态。

## 2026-10-19 统一验证结果

按用户最新通知完成自动检查、构建与 macOS 隔离空间实测。140 帧均可解码、非空且 alpha>96 的轮廓距各帧边缘至少 8 像素。修正了原始单元格中心偏移导致尾巴裁切的问题；坐姿待机、拿书、阅读、翻页与合书按约 265 像素轮廓高度归一，睡眠/醒来约 220 像素，减少跨动作突变。前端 79 项通过，包含 Canvas 时间推进、完成序号、隐藏暂停、减少动态效果、解码失败、回退和姿态队列；Debug 与 Release app/DMG 已构建。

macOS 已检查 20 个预览入口、坐下拿书/阅读、互动后恢复阅读、睡眠/醒来、左右走动、拖动落地、三档大小、小窗菜单滚动、Escape 和双击返回。独立 AI 绘制帧仍有脸部、头发和服装位置差异，混合期间可见重影，连续观感尚未通过。没有采集 WKWebView 帧时长分位值，不能声称“已证明不卡顿”。隐藏/减少动态效果目前为自动化验证；Windows、多屏和系统缩放仍待实机。详细证据见项目 docs/evidence/navigation-desktop-pet.md。

## 2026-10-19 顿挫与重影修复

保留 20 动作、140 个绘制帧，不改写素材像素或复制假帧。新增坐标校准脚本与逐帧变换：待机头部轮廓质心横向跨度约 17.3 像素、阅读约 19.09 像素，校正后在数值舍入误差范围内。该指标不代表脸部内容完全一致；全部变换后的 alpha>96 轮廓保持在画布内并留有约 8 像素边距。待机、坐姿和阅读循环最多作 4% 的纵向校准，单次弯腰和点头保留原动作变化。

前端 20 文件 / 84 项测试、类型、lint 和构建通过。macOS 已复查待机、坐下拿书、阅读、互动合书与恢复阅读、进入休息过渡。Release app/DMG 已更新，签名和镜像校验通过。同页浏览器五秒对比：待机 drawImage 由 360 次降至 15 次，阅读由 362 次降至 20 次；双方各 300 次 rAF 回调，无超过 50 ms 的回调间隔。只说明绘制调用减少，不代表整机性能提高 95% 或 WKWebView 保证无掉帧。具体采样和限制见项目验收记录。
